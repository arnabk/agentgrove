## 2. Starting fresh on another machine

```bash
# Prereqs (macOS): brew install node pnpm just; rustup toolchain install 1.95.0
git clone https://github.com/arnabk/agentgrove.git
cd agentgrove
just setup            # rust components, pnpm install, playwright, git hooks

# Toolchain gotcha: Homebrew cargo (1.83) CANNOT parse edition 2024.
# Always put the pinned toolchain first on PATH for BE builds:
export PATH="$HOME/.rustup/toolchains/1.95.0-aarch64-apple-darwin/bin:$PATH"

# Back up notes before any BE restart, then launch (BE + FE, hot reload):
mkdir -p /tmp/ag-notes-backup && cp .data/scratchpads/*.json /tmp/ag-notes-backup/ 2>/dev/null
nohup bash scripts/dev.sh > .data/logs/dev-wrapper.log 2>&1 &
```

Check before launching (skip if already up):

```bash
curl -fsS http://127.0.0.1:4317/health                 # BE
curl -fsS -o /dev/null -w "%{http_code}" http://localhost:5173   # FE -> 200
```

Notes:

- Dev data lives in `.data/` (SQLite DB, scratchpads, logs). It is **local to the machine** and not in git — a fresh clone starts empty. Projects/chats/worktrees you had on the old machine won't follow you unless you copy `.data/` across.
- First BE build after a clean checkout / machine restart takes ~1–2 min (cargo build).
- Logs: `.data/logs/dev-backend.log`, `.data/logs/dev-frontend.log`, `.data/logs/client.log` (memory monitor).

## 3. Recent work shipped (v0.1.53 → v0.1.57)

- **Queue is now manual-only** (`v0.1.57`). `is_auto` is a hard `false`; nothing auto-sends. Messages sent while the agent is busy park in the queue and dispatch only when the user clicks "Send next". The auto/manual toggle is gone from the UI; `set_mode` is a 204 no-op kept for wire compat. Dispatched cards are removed optimistically so they no longer linger until refresh. (`crates/agentgrove-api/src/queue.rs`, `apps/web/src/components/QueueTimeline.tsx`, `apps/web/src/panes/ChatPane.tsx`.)
- **Terminals survive a page refresh** (`v0.1.57`). An unexpected terminal WS close used to `destroyTab()`, which also deleted the tab from the saved layout — so a restored terminal whose PTY was gone wiped itself. Now a lost connection retries once (BE replays scrollback); only if that fails is the terminal marked "dead" **without** removing the tab, showing a "session ended → Restart shell" overlay that respawns a PTY in the same cwd and rebinds the tab in place. Clean `exit`/Ctrl+D still closes the tab. Added `replaceTerminalId()`. (`apps/web/src/panes/TerminalPane.tsx`, `apps/web/src/stores/app.ts`, `apps/web/src/App.tsx`.)
- **README is the single feature list** (`v0.1.57`). Deleted the duplicated `docs/features.md`; the root README carries the full, expanded feature list and one combined demo video.
- **Client memory/OOM guards** — bounded chat window (600 prompts / 400 events per prompt) + terminal scrollback (2000 lines), throttled memory accounting; GalaxyMap resize-listener leak fixed.
- **Stale opencode session recovery** — on `Session not found`, the BE clears `session_id`, retries with recent context, keeps the chat alive.
- **`/compact`** — summarizes the conversation and starts a fresh provider session in place.
- **Demo recorder fixes + combined demo video** — `docs/demos/agentgrove-demo.mp4` (~5:49), recorded in the isolated Docker stack.
- **Announcements** — dev.to + Medium comments bumped for the release. HN is rate-limited; Reddit is blocked on the shared Chrome — both excluded from launch channels going forward.
